# FIXORA HOME

A modern portfolio landing page concept for a fictional home repair and maintenance service.

## Stack

- React 19 + TypeScript 6
- Vite 8
- Tailwind CSS 4
- Lucide React
- React Hook Form + Zod
- Motion for React

## Requirements

- Node.js 22.12.0 or newer
- npm 10 or newer

## Getting started

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run typecheck
npm run lint
npm run format:check
npm run build
```

## Project notes

This is a demonstration project. Forms and chat interactions will be simulated locally; no personal data is submitted to a server.
