# FIXORA HOME

Демонстрационный адаптивный лендинг сервиса бытовых и технических услуг для дома.

**Демо:** https://artkoro94.github.io/fixora-home/

FIXORA HOME — портфолио-проект с акцентом на современный интерфейс, адаптивную вёрстку, доступность и производительность. Сайт полностью на русском языке.

## Возможности

- Адаптивная главная страница для мобильных устройств, планшетов и компьютеров.
- Навигация по основным разделам сайта.
- Презентация направлений услуг, преимуществ и этапов работы.
- Контактный блок с переходом к звонку по телефону.
- Форма обращения с маской российского номера и проверкой полей.
- Модальное подтверждение успешной проверки формы.
- Локальные оптимизированные изображения для главного экрана.
- SEO-метаданные, Open Graph, favicon, robots.txt и sitemap.xml.

> **Важно:** это демонстрационный сайт. Форма не отправляет данные на сервер, а модальное окно показывает только результат локальной проверки. Реальная обработка заявок и каналы связи не подключены.

## Технологии

- **React 19** — интерфейс.
- **TypeScript 6** — типизация.
- **Vite 8** — сборка и локальная разработка.
- **Tailwind CSS 4** — подключённая система стилей и дизайн-токены.
- **Lucide React** — иконки.
- **React Hook Form** и **Zod** — управление формой и валидация.
- **Motion** — библиотека анимаций.

## Требования

- Node.js 22.12.0 или новее.
- npm 10 или новее.

## Локальный запуск

Клонируйте репозиторий:

```bash
git clone https://github.com/artkoro94/fixora-home.git
cd fixora-home
```

Установите зависимости и запустите dev-сервер:

```bash
npm install
npm run dev
```

Vite выведет локальный адрес сайта в терминале. Чтобы браузер открывался автоматически, используйте:

```bash
npm run dev -- --open
```

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Запуск локального сервера |
| `npm run build` | Проверка TypeScript и production-сборка |
| `npm run preview` | Просмотр production-сборки |
| `npm run typecheck` | Проверка типов TypeScript |
| `npm run lint` | Проверка ESLint |
| `npm run format` | Форматирование Prettier |
| `npm run format:check` | Проверка форматирования |

Перед публикацией изменений рекомендуется выполнить:

```bash
npm run typecheck
npm run lint
npm run format:check
npm run build
```

## Публикация

Проект публикуется на GitHub Pages через GitHub Actions. Workflow собирает приложение и размещает содержимое папки `dist` после обновления ветки `main`.
